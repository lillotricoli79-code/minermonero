Package status: integration work in progress; not a final mining release.

Implemented in this branch:
- Base Tkinter controller with pool/wallet/worker/password/TLS, profiles, start/stop,
  local restricted XMRig API, live hashrate/share/uptime fields and log window.
- Advanced CPU settings in GUI: thread hint, priority, affinity mask and RandomX mode.
- PowerShell shell controller: Configure / Start / Stop / Status.
- Staged official XMRig downloader with validation and backup of the previous executable.
- Optional hardware sensor reader using LibreHardwareMonitor WMI; unavailable sensors
  are reported as unavailable, never replaced with fabricated readings.
- Source bundle builder (PowerShell + BAT) for base + AI Qween and SHA256 manifest.
- AI Qween advisor module with regression tests; advisory only, not automatic control.
- GitHub Actions validation for Python syntax, AI tests, PowerShell parsing and
  Windows source-bundle generation.

Still not verified / not implemented:
- The Tkinter dashboard does not yet display hardware temperatures, fan RPM or GPU
  telemetry; hardware_sensors.ps1 is a separate diagnostic tool.
- GPU OpenCL/CUDA mining depends on the downloaded XMRig build, installed drivers
  and hardware; no GPU device has been tested here.
- Pool connectivity and real mining shares/hashrate have not been verified against
  a live pool and wallet.
- AI Qween is not yet fed continuous sensor samples and does not apply tuning.
- A real Stratum proxy is not included.
- Windows 10 runtime behavior and standalone EXE build still require on-device testing.

Safety:
- Original source ZIP archives are preserved.
- The official XMRig engine is downloaded separately; this repository does not contain
  a prebuilt miner binary.
- No synthetic temperature, fan, power, share, hashrate or earnings values are used.
- Do not expose the XMRig HTTP API outside loopback.
